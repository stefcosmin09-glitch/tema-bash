# 🐚 Bash Scripting — Tema

Proiect realizat în cadrul cursului **DevOps Online — IT School**.
Conține 13 exerciții practice de Bash orientate spre automatizare, administrare sisteme Linux și DevOps real.

---

## 📁 Structura proiectului

| Fișier | Descriere |
|--------|-----------|
| `exercitiul_1.sh` | Variabile, input utilizator și operații de bază |
| `exercitiul_2.sh` | Control flow — if/elif/else și comparații |
| `exercitiul_3.sh` | Bucle — for și while |
| `exercitiul_5.sh` | Funcții în Bash |
| `exercitiul_6.sh` | Procesare text cu grep, sed, awk |
| `exercitiul_7.sh` | Argumente din linia de comandă |
| `exercitiul_8.sh` | Array-uri și operații pe liste |
| `exercitiul_9.sh` | Operații pe fișiere și directoare |
| `exercitiul_10.sh` | Procesare fișiere de configurare |
| `exercitiul_11.sh` | Parsare și analiză fișiere de log |
| `exercitiul_12.sh` | Monitorizare sistem |
| `exercitiul_13.sh` | Automatizare și scripting avansat |
| `config.sh` | Fișier de configurare partajat |

---

## 🚀 Cum rulezi

### Permisiuni de execuție
```bash
chmod +x *.sh
```

### Rulare exercițiu individual
```bash
./exercitiul_1.sh
./exercitiul_2.sh
# etc.
```

## 🛠️ Tehnologii și comenzi folosite

- **Bash** scripting avansat
- `grep`, `sed`, `awk` — procesare text
- `find`, `ls`, `cp`, `mv` — operații pe fișiere
- `sha256sum` — verificare integritate
- `curl` — HTTP requests din terminal
- `crontab` — automatizare periodică
- `while`, `for`, `if/elif/else` — control flow
- Array-uri și funcții Bash

---

## 📚 Concepte acoperite

- Variabile și tipuri de date în Bash
- Control flow — condiții și bucle
- Funcții și modularitate
- Procesare text cu unelte Linux
- Argumente din linia de comandă `$1`, `$2`
- Operații pe fișiere și directoare
- Array-uri în Bash
- Parsare fișiere de log
- Monitorizare sistem
- `set -euo pipefail` — scripturi robuste
- Coduri ANSI pentru culori în terminal
